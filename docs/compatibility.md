# 模板兼容性

EvalDesk 按表头语义解析评测表，不依赖工作簿名、固定列数或固定起始列。

## 已覆盖

- 图片五维和视频八维评分
- 单输出和多输出评分
- 0、1 或多轮历史结果对照
- 仲裁标签与整体仲裁
- 普通评测和盲评后 Review
- 标准六字段与旧版五字段布局
- JSON、英文逗号、中文逗号及顿号分隔的分数序列
- 按物理行和写入白名单生成回写预览

## 安全边界

- 表格读取与本地评分不会修改飞书。
- `results.json` 是唯一评分结果来源。
- `commit_results.py` 默认只生成差异预览。
- 只有显式使用 `--apply` 才会写回，并在写后逐格校验。
- 机器分、历史轮次、其他模型和专家字段默认只读。
- 测试仅使用 `example.test` 匿名合成数据，不包含真实飞书链接或业务内容。

## 尚未覆盖

- 跨子表自动关联机器评分
- 工作簿级子表导航
- 专家字段编辑模式
- 超过 1,000 行的自动分页

新模板上线前，应依次验证表头解析、会话生成、页面展示、本地保存、
回写预览和确认后的真实回写。
